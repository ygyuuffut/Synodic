# SYNODIC - A SugarCube Game Modding API & UI

This repository intends to host Synodic core dependency releases while provides an entry point for all issues and suggestions.

## Getting Started

Refer to [Theia](https://github.com/ygyuuffut/Theia), the all-in-one packager dedicated for the STG html game, which includes the modding services

## Known Issues

### Intermittent Chrome Page Crash (Error 5)
A Chrome renderer crash was previously observed on mobile Chrome Browser (viewport + ADB device). The issue has not been reproducible, and its root cause remains undetermined.
As the failure occurs outside the normal JavaScript exception-handling environment, SYNODIC Recovery may not be able to capture diagnostic information.
Investigation will continue if additional reproducible cases become available.
